# Sunshine Systems Projetos — Site

Site institucional em página única (HTML/CSS/JS puro, sem build) para a
Sunshine Systems Projetos — instalação e manutenção de elétrica, câmeras,
interfonia, automatizadores, redes, controle de acesso e automação.

## Estrutura

- `index.html` — página inteira (estilo e script embutidos, sem dependências
  além de fontes do Google Fonts)

## Deploy no Vercel

1. Suba este repositório no GitHub (veja abaixo).
2. Em https://vercel.com, clique em **Add New → Project**.
3. Selecione o repositório `sunshine-systems-site`.
4. Framework preset: **Other** (site estático). Não precisa de build command
   nem output directory — o Vercel serve o `index.html` direto.
5. Clique em **Deploy**.
